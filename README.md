# こっぷるん 3D WebAR — デザイン確認版

## 含まれるもの
- `index.html` — 3D表示と対応スマホでのAR起動
- `koppurun.glb` — 試作3Dモデル（非公式、ロゴ未収録）

## 公開する前に
このモデルは公式の3Dデータではなく、参考写真から制作した簡易造形です。公式キャラクターのデザイン、名称、ロゴの使用・改変・公開には権利者の確認と承認が必要です。承認が得られるまでは非公開の検証用として扱ってください。

## GitHub Pages
1. 権利者から公開許可を得た後、GitHubでPublicリポジトリを作成。
2. `index.html`と`koppurun.glb`をリポジトリ直下へアップロード。
3. Settings → Pages → Deploy from a branch → main → /(root) → Save。
4. 公開URLをHTTPSで開き、スマホで確認。

**注意:** GitHub Pagesは原則Publicリポジトリでの公開が必要なプランがあります。非公開のまま動作確認したい場合はローカル開発サーバーなどを使い、外部公開しないでください。ローカルファイルを直接開くとモデルが読み込めない場合があります。

## 動作・制限
- 3D表示は `<model-viewer>` を利用。ネット接続が必要です。
- AndroidではWebXRまたはScene Viewer、iOSではQuick Lookが端末の条件によって利用できます。
- iOSのUSDZは `<model-viewer>` の対応環境では自動生成される場合がありますが、すべての端末での起動を保証しません。
- サイズ切替はWebプレビューで動作。外部ARビューアでは設定が引き継がれない場合があります。
- 手振りアニメーション、記念撮影、公式デザインの忠実な再現は未実装です。
- 公開前に著作権・商標権、依存ライブラリ、実機動作を検証してください。
